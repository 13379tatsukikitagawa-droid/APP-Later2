プライバシーポリシー

制定日 20XX年XX月XX日 ・ 最終改定日 20XX年XX月XX日

【運営者名】(以下「運営者」)は、写真共有アプリ「Later」(以下「本アプリ」)において、ユーザーの個人情報やプライバシーを大切に取り扱います。このプライバシーポリシーでは、本アプリで取得する情報と、その使い方をご説明します。

01取得する情報

本アプリでは、次の情報を取得します。

  • アカウント情報:表示名(ニックネーム)、アイコン、認証のための識別子(例:メールアドレス、Apple ID の識別子など、実際の認証方式に合わせて記載)
  • 投稿コンテンツ:撮影した写真、撮影日時、選択したタグ(ことば)
  • グループ情報:参加しているグループ、メンバー、合言葉・リンク・QRによる参加の履歴
  • 国・地域の情報:Mondo に、投稿者の「国・地域」を表示するための情報(端末の位置情報から都道府県・国レベルに丸めて取得するのか、設定した国・地域を使うのか、実際の仕様に合わせて記載)。正確な位置情報(緯度・経度)は、他のユーザーには表示しません。
  • 端末・利用情報:端末の種類、OSのバージョン、アプリのバージョン、言語設定、プッシュ通知のためのトークン、操作ログ、クラッシュ情報
  • お問い合わせの内容:お問い合わせや通報の際にいただいた情報

本アプリは、写真を撮影するためにカメラへのアクセス、通知を送るために通知の許可、(必要な場合)位置情報の許可をお願いすることがあります。許可は、端末の設定からいつでも変更できます。

02利用目的

  1. 本アプリの提供、運営、維持(写真の現像・共有、グループ機能、Mondo の表示など)
  2. ユーザー認証、不正利用の防止、安全の確保
  3. 通報や問い合わせへの対応、規約違反への対応
  4. 通知(現像が完了したときなど)の送信
  5. 本アプリの改善、新機能の開発、利用状況の分析(個人を特定しない形で行います)
  6. 重要なお知らせの連絡

03写真が表示される範囲

  • グループ:写真は、そのグループのメンバーにのみ表示されます。
  • Mondo:写真は、匿名の表示名と丸いアイコン、国・地域のみとともに、他のユーザーに表示されます。氏名、フォロー、いいねの情報などは表示しません。
  • ご自身:撮影した写真は、カレンダーなどで、ご自身が見返せます。

04第三者への提供

運営者は、次の場合を除き、ユーザーの個人情報を、本人の同意なく、第三者に提供しません。

  1. 法令に基づく場合
  2. 人の生命、身体、財産の保護のために必要で、本人の同意を得ることが困難な場合
  3. 国の機関、地方公共団体などの法令に定める事務の遂行に協力する必要がある場合
  4. 利用目的の達成に必要な範囲で、業務を委託する場合(次項)

05外部サービス・委託先

本アプリは、サービスの提供のために、次のような外部サービスを利用します。これらの事業者が、各社のポリシーに従って情報を取り扱うことがあります。

  • Apple(App Store、TestFlight、プッシュ通知サービス)
  • 【データの保存・認証に使うクラウドサービス名(例:Firebase / Supabase / AWS など)】
  • 【利用状況・クラッシュの分析に使うサービス名(使用している場合)】

個人情報が、日本国外にあるサーバーで保管、処理される場合があります。この場合も、適切な安全管理措置を講じます。

06保管期間・削除

  1. 取得した情報は、利用目的に必要な期間、保管します。
  2. ユーザーは、アプリ内の設定から、いつでもアカウントを削除できます。削除を行うと、アカウント情報、投稿コンテンツ、グループへの参加情報は、合理的な期間内に削除します(バックアップ等に、一定期間残る場合があります)。
  3. Mondo などに表示された写真は、【表示期間(例:撮影の翌日まで)】を過ぎると、他のユーザーに表示されなくなります。
  4. 法令に基づき保存が必要な情報は、その期間、保管します。

07未成年者の方へ

本アプリは、13歳未満の方には、ご利用いただけません。未成年の方は、保護者の方と、このポリシーと利用規約をお読みください。他のユーザーの顔や、学校名、住所、連絡先などの個人情報が分かる写真は、撮影・投稿しないでください。

08安全管理

運営者は、個人情報の漏えい、滅失、毀損を防ぐために、通信の暗号化、アクセス権限の管理など、必要かつ適切な安全管理措置を講じます。ただし、インターネット上の通信やデータの保管について、完全な安全性を保証するものではありません。

09開示・訂正・利用停止・削除の請求

ユーザーは、運営者が保有する自己の個人情報について、法令の定めに従い、開示、訂正、追加、削除、利用の停止などを請求できます。請求は、下記のお問い合わせ窓口にご連絡ください。ご本人であることを確認したうえで、合理的な期間内に対応します。アカウントの削除は、アプリ内の設定から、ご自身で行うこともできます。

10Cookie・アクセス解析について(ウェブサイト)

本ウェブサイト(紹介ページ)では、表示の設定(触覚・音のオン/オフ)をお使いのブラウザに保存します。これは、お使いの端末の中だけに保存され、運営者には送信されません。(アクセス解析ツールを使う場合は、その内容と、オプトアウトの方法を記載してください)

11ポリシーの変更

運営者は、法令の変更やサービスの変更などに応じて、このポリシーを、変更することがあります。変更後のポリシーは、本アプリまたは本ウェブサイトに掲載した時点から効力を生じます。重要な変更を行う場合は、アプリ内などで、お知らせします。
