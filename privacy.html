# Privacy policy

プライバシーポリシー

Tatsuki Kitagawa 北川達大(以下「運営者」)は、写真アプリ「Lattag」(以下「本アプリ」)で、ユーザーの個人情報とプライバシーを大切に取り扱います。このページでは、本アプリが取得する情報と、その使いみちを説明します。

かんたんに 言うと
  • 取得するのは、アプリを動かすのに必要な情報だけです。広告のために情報を売ったり、渡したりしません。
  • 位置情報は、市区町村までに丸めます。Mondo に出るのは、国と都道府県までです。
  • 写真は 7日で消えます。★ をつけた 1枚だけが、1年のこります。
  • アカウントは、アプリの設定から、いつでも消せます。

01取得する情報

本アプリは、次の情報を取得します。

種類内容
アカウント表示名、ユーザーID、アイコンの写真、ログインのための情報(「Apple でサインイン」の識別子、またはメールアドレス)
撮影したもの写真、動画(音声を含む場合があります)、撮影した日時、タグ(ことば)、キャプション、写真につけた曲の情報
つながりともだち、グループ、Trip のメンバー、招待リンク・合言葉・QR・「ふって つながる」による参加の記録、ブロックした相手
やりとりグループやともだちとのメッセージ、リアクション、コメント
位置情報端末の位置情報から、市区町村・都道府県・国のレベルに丸めた地名のみを取得します。Mondo には、都道府県・国のレベルまでを表示します。正確な位置(緯度・経度)は、ほかのユーザーに表示しません。
端末・利用状況端末の種類、OS とアプリのバージョン、言語の設定、プッシュ通知のためのトークン、エラーの記録
お問い合わせお問い合わせや通報のときに、いただいた内容

端末へのアクセス許可

本アプリは、次の許可をお願いすることがあります。許可は、端末の「設定」からいつでも変更できます。

  • カメラ:写真・動画の撮影、QR の読み取りのため
  • マイク:動画に音声を記録するため
  • 位置情報:写真に地名(市区町村まで)をつけ、Mondo に国・都道府県を表示するため
  • 通知:朝 9:00 に写真がひらいたとき、ともだちからの申請があったときなどにお知らせするため
  • モーション(端末の動き):「ふって つながる」で、近くのともだちとつながるため
  • 写真ライブラリ:写真を端末に保存するとき、アイコンの写真をえらぶとき

02利用目的

  1. 本アプリの提供と運営(写真の現像と共有、ともだち・グループ・Trip・Mondo・Recap の表示など)
  2. ログイン、本人の確認、不正な利用の防止
  3. 通報やお問い合わせへの対応、利用規約に違反する行為への対応
  4. 通知の送信
  5. 不具合の調査、本アプリの改善(個人を特定しない形で行います)
  6. 重要なお知らせの連絡

運営者は、広告を配信する目的で、ユーザーの情報を利用しません。

03写真が見える範囲

撮った写真は、あしたの朝 9:00 にひらくまで、本人を含めてだれにも表示されません。ひらいたあと、写真ごとに「友だちに公開」か「自分だけ」をえらべます。

場所見える相手いっしょに表示されるもの
ME本人だけ—
Friendsつながっているともだち(12人まで)。ともだちの写真は、その日に 1枚撮った人だけが見られます。表示名、アイコン、タグ、撮った時刻、地名(市区町村まで)
Groupsそのグループのメンバー(4〜8人)表示名、アイコン、タグ、メッセージ
Tripその Trip に参加しているメンバー表示名、アイコン、タグ
Mondo本アプリのほかのユーザータグ、国・都道府県。氏名や正確な場所は表示しません。

Mondo に公開する写真は、表示する前に、自動の画像チェックを行います。不適切と判断したもの、通報が重なったものは、表示しません。

04第三者への提供

運営者は、次の場合を除いて、本人の同意なく、個人情報を第三者に提供しません。

  1. 法令にもとづく場合
  2. 人の生命、身体、財産を守るために必要で、本人の同意を得ることがむずかしい場合
  3. 国の機関や地方公共団体などが、法令で定められた事務を行うことに協力する必要がある場合
  4. 利用目的の達成に必要な範囲で、業務を委託する場合(次の「外部サービス」をごらんください)

05外部サービス

本アプリは、サービスを提供するために、次の外部サービスを利用しています。これらの事業者は、それぞれのプライバシーポリシーに従って情報を取り扱います。

事業者使いみち
Appleアプリの配信(App Store、TestFlight)、「Apple でサインイン」、データの保存(iCloud / CloudKit)、プッシュ通知
Googleログインの認証(Firebase Authentication)、招待リンクのページ(Firebase Hosting)
CloudflareMondo の集計と、公開前の自動の画像チェック(Cloudflare Workers / Workers AI)
Apple Music / Spotify写真に曲をつける機能(ユーザーが自分でつないだ場合のみ)

これらのサービスにより、情報が日本国外のサーバーで保管・処理されることがあります。この場合も、運営者は適切な安全管理を行います。

本アプリは、広告のための追跡(トラッキング)を行っていません。

06保管期間・削除

  1. 写真・動画:ひらいてから 7日で消えます。★ をつけた写真(1日に 1枚)は、1年のこります。
  2. メッセージ:グループやともだちとのメッセージは、7日で消えます。
  3. Mondo の写真:表示がおわったあと、一定の期間(おおむね 48時間)でサーバーから削除します。
  4. アカウントの削除:アプリの「設定」から、いつでもアカウントを消せます。消すと、アカウントの情報、写真、つながりの情報を、合理的な期間内に削除します(バックアップなどに、一定の期間のこる場合があります)。
  5. 法令により保存が必要な情報は、その期間、保管します。

07未成年の方へ

本アプリは、13歳未満の方にはご利用いただけません。未成年の方は、保護者の方といっしょに、このポリシーと利用規約を読んでから使ってください。

ほかの人の顔や、学校名、住所、連絡先などが分かる写真は、その人の了解なしに撮ったり、公開したりしないでください。

08安全管理

運営者は、個人情報の漏えい、紛失、破損を防ぐために、通信の暗号化、アクセス権限の管理など、必要かつ適切な安全管理を行います。ただし、インターネット上の通信やデータの保管について、完全な安全を保証するものではありません。

09開示・訂正・削除の請求

ユーザーは、運営者が持っている自分の個人情報について、法令の定めに従って、開示、訂正、追加、削除、利用の停止などを求めることができます。下の「お問い合わせ窓口」までご連絡ください。ご本人であることを確認したうえで、合理的な期間内に対応します。

アカウントの削除は、アプリの「設定」から、ご自身で行うこともできます。

10このウェブサイトについて

このウェブサイト(紹介ページ)は、Cookie やアクセス解析ツールを使っていません。

文字の表示のために Google Fonts を、ページの配信のために GitHub Pages を利用しています。ページを開くと、お使いの端末の IP アドレスなどが、これらの事業者に送信されます。

11ポリシーの変更

運営者は、法令やサービスの内容の変更に応じて、このポリシーを変更することがあります。変更したポリシーは、本アプリまたはこのウェブサイトに掲載した時点から効力を持ちます。重要な変更をするときは、アプリ内などでお知らせします。
